Literate Emacs configuration. Tangled and loaded by =init.el= via
=org-babel-load-file=.

* Prelude

Ensures the tangled =config.el= starts with a =lexical-binding= cookie.

#+begin_src emacs-lisp
;;; config.el --- Tangled Emacs configuration -*- lexical-binding: t; -*-
#+end_src

* Package Management

Emacs packages are provided by Nix (see [[file:flake.nix][=flake.nix=]] and [[file:nix/hm-module.nix][=nix/hm-module.nix=]]):
the flake builds Emacs with every package below on =load-path=, so =use-package=
forms carry no =:ensure=/=:straight= and install nothing at runtime. Built-in
features (=emacs=, =eglot=, =org=, =dired=, …) use =:ensure nil=. To add a
package, add it to the =withPackages= list in =flake.nix= and rebuild.

** Garbage collection

=early-init.el= raises =gc-cons-threshold= to 1GB for fast startup but never
lowers it again, so GC almost never runs and eventually fires as a long pause
(often mid-completion). =gcmh= keeps the threshold tiny while typing and large
while idle, moving collection out of interactive work.

#+begin_src emacs-lisp
(use-package gcmh
  :init
  (gcmh-mode 1)
  :custom
  (gcmh-high-cons-threshold (* 128 1024 1024)))
#+end_src

#+begin_src emacs-lisp
(use-package dired
  :ensure nil
  :custom
  (dired-dwim-target t)
  (dired-guess-shell-alist-user
   '(("\\.\\(png\\|jpe?g\\|tiff\\)" "feh" "xdg-open" "open")
     ("\\.\\(mp[34]\\|m4a\\|ogg\\|flac\\|webm\\|mkv\\)" "mpv" "xdg-open" "open")
     (".*" "open" "xdg-open")))
  (dired-kill-when-opening-new-dired-buffer t)
  :config
  (when (eq system-type 'darwin)
    (let ((gls (executable-find "gls")))
      (when gls
        (setq insert-directory-program gls))))
  (setq dired-listing-switches
        "-l --almost-all --human-readable --group-directories-first --no-group")
  (put 'dired-find-alternate-file 'disabled nil)
  (defun my/dired-find-file-reuse ()
    "Open a directory in place (reusing the dired buffer); open files normally.
`dired-kill-when-opening-new-dired-buffer' only reuses the buffer when it is
shown in fewer than two windows (the `(< (length (get-buffer-window-list)) 2)'
guard in `dired--find-possibly-alternative-file'); with the buffer in two or
more windows RET falls back to `find-file' and spawns a new buffer.  This
reuses unconditionally for directories via `find-alternate-file'."
    (interactive)
    (let ((file (dired-get-file-for-visit)))
      (if (file-directory-p file)
          (progn (set-buffer-modified-p nil)
                 (find-alternate-file file))
        (find-file file))))
  ;; evil-collection binds RET -> dired-find-file when it initialises, which
  ;; happens (on `evil-mode') after this :config's own `with-eval-after-load'
  ;; has run -- so it would clobber a rebind made here directly.  Install ours
  ;; from `dired-mode-hook', which runs when a dired buffer is created, i.e.
  ;; after evil-collection has set up `dired-mode-map', so ours wins.
  (defun my/dired-rebind-return ()
    (when (fboundp 'evil-collection-define-key)
      (evil-collection-define-key 'normal 'dired-mode-map
        (kbd "RET") 'my/dired-find-file-reuse)))
  (add-hook 'dired-mode-hook #'my/dired-rebind-return))
#+end_src

** Dirvish

[[https://github.com/alexluigit/dirvish][=dirvish=]] is a polished front-end for dired. =dirvish-override-dired-mode=
routes every dired entry point (=dired=, =dired-jump=, the =<leader> x= bindings)
through dirvish, inheriting the dired settings above (listing switches,
single-buffer navigation). =nerd-icons= is already installed, so it supplies the
file glyphs. Rich previews (images, PDF, video) want extra CLI tools on =PATH=
(e.g. =ffmpegthumbnailer=, =poppler=, =mediainfo=); text/directory previews work
without them.

=dirvish-side= is the file-tree sidebar (replaces neotree): a project-rooted
panel on the right, matching neotree's width. =dirvish-side-follow-mode= keeps it
pointed at the current file, and TAB (=dirvish-subtree-toggle=) expands
subdirectories inline for tree-like navigation. Bound to =<leader> e= (see the
keybindings section), which toggles it.

#+begin_src emacs-lisp
(use-package dirvish
  :hook ((after-init . dirvish-override-dired-mode)
         (after-init . dirvish-side-follow-mode))
  :commands (dirvish-side)
  :custom
  (dirvish-attributes '(nerd-icons file-size))
  (dirvish-side-width 50)
  (dirvish-side-attributes '(nerd-icons file-size))
  (dirvish-side-display-alist '((side . right) (slot . -1)))
  :config
  ;; The subtree nesting guides (`dirvish-subtree-prefix' = " │") are text
  ;; glyphs, so the global `line-spacing' (0.2) breaks them into disconnected
  ;; segments. Drop the extra spacing in dirvish/dired buffers so the bars
  ;; join up; prose/code buffers keep the global line-spacing.
  (defun my/dirvish-tighten-line-spacing ()
    (setq-local line-spacing 0))
  (add-hook 'dired-mode-hook #'my/dirvish-tighten-line-spacing))
#+end_src

** Themes

Auto-switches Catppuccin between Latte (light) and Mocha (dark) following the
system appearance. [[https://github.com/LionyxML/auto-dark-emacs][=auto-dark=]] provides the detection cross-platform (D-Bus on
Linux, =ns-system-appearance=/AppleScript/=osascript= on macOS), so this works
the same on Linux and Darwin, in GUI and terminal frames. When no detection
mechanism exists (e.g. a Linux TTY with no D-Bus session bus) it falls back to a
fixed dark flavor rather than warning at startup.

#+begin_src emacs-lisp
(use-package catppuccin-theme
  :config
  (defun my/catppuccin-flavor-for (appearance)
    "Return the catppuccin flavor symbol for system APPEARANCE.
APPEARANCE is `light' or `dark'.  Pure: no side effects, so it can be
unit-tested without loading a theme."
    (if (eq appearance 'light) 'latte 'mocha))
  (defun my/apply-diff-hl-faces ()
    "Colour the diff-hl faces from the active catppuccin flavor.
Called on every flavor switch (and when diff-hl loads) so the fringe/margin
indicators track Latte/Mocha instead of being pinned to one palette.
No-op until diff-hl has loaded and defined its faces: the initial flavor is
applied by the auto-dark block at startup, before the `:defer'red diff-hl
package exists, and `set-face-attribute' on an undefined face errors.  The
diff-hl block re-invokes this once its deffaces have run."
    (when (facep 'diff-hl-change)
      (set-face-attribute 'diff-hl-change nil :background 'unspecified
                          :foreground (catppuccin-color 'blue))
      (set-face-attribute 'diff-hl-delete nil :background 'unspecified
                          :foreground (catppuccin-color 'red))
      (set-face-attribute 'diff-hl-insert nil :background 'unspecified
                          :foreground (catppuccin-color 'green))))
  (defun my/apply-monaspace-role-faces ()
    "Point theme-restyled faces at their Monaspace role variant.
Re-applied on every flavour switch because `catppuccin-reload' resets face
specs (the same reason `my/apply-diff-hl-faces' exists).  Italics use Radon
\(script); headings use Krypton (mechanical, for structure); the mode line uses
Argon (humanist sans, for UI chrome).  Heading faces are guarded with `facep'
since org/markdown are deferred and their faces may not exist yet at startup --
the org and markdown-mode blocks re-invoke this once they load."
    ;; Base font. catppuccin owns the `default' face (fg/bg), so `catppuccin-reload'
    ;; re-specs it and strips the family/size/weight -- re-apply them here.
    ;; (variable-pitch/fixed-pitch are NOT themed by catppuccin, so they stay set
    ;; once in the font block below.)
    (set-face-attribute 'default nil :font "MonaspiceNe Nerd Font"
                        :height 140 :weight 'medium)
    ;; Italics in Radon. These faces are restyled by `catppuccin-reload'
    ;; (comment/keyword lose their slant entirely), so they must be set here --
    ;; from the flavour hook -- not just once at top level, or a light/dark
    ;; switch (or auto-dark's startup re-apply) drops italics everywhere.
    (dolist (face '(italic font-lock-comment-face font-lock-keyword-face))
      (set-face-attribute face nil :family "MonaspiceRn Nerd Font" :slant 'italic))
    (dolist (n (number-sequence 1 8))
      (let ((face (intern (format "org-level-%d" n))))
        (when (facep face)
          (set-face-attribute face nil :family "MonaspiceKr Nerd Font"))))
    (dolist (n (number-sequence 1 6))
      (let ((face (intern (format "markdown-header-face-%d" n))))
        (when (facep face)
          (set-face-attribute face nil :family "MonaspiceKr Nerd Font"))))
    (set-face-attribute 'mode-line nil :family "MonaspiceAr Nerd Font")
    (set-face-attribute 'mode-line-inactive nil :family "MonaspiceAr Nerd Font"))
  (defun my/apply-catppuccin-flavor (appearance)
    "Set and reload the catppuccin flavor for system APPEARANCE (`light'/`dark')."
    (setq catppuccin-flavor (my/catppuccin-flavor-for appearance))
    (catppuccin-reload)
    (let ((bg (face-attribute 'mode-line :background)))
      (set-face-attribute 'mode-line nil :box `(:line-width 6 :color ,bg))
      (set-face-attribute 'mode-line-inactive nil :box `(:line-width 6 :color ,bg)))
    (my/apply-diff-hl-faces)
    (my/apply-monaspace-role-faces)))

(use-package doom-themes
  :custom
  (doom-themes-enable-bold t)
  (doom-themes-enable-italic t)
  :config
  (load-theme 'catppuccin t)
  (doom-themes-visual-bell-config)
  (doom-themes-treemacs-config)
  (doom-themes-org-config))

(setq custom-safe-themes
      '("87fa3605a6501f9b90d337ed4d832213155e3a2e36a512984f83e847102a42f4"
        "4594d6b9753691142f02e67b8eb0fda7d12f6cc9f1299a49b819312d6addad1d"
        "7771c8496c10162220af0ca7b7e61459cb42d18c35ce272a63461c0fc1336015"
        "276228257774fa4811da55346b1e34130edb068898565ca07c2d83cfb67eb70a"
        default))

;; Drive the flavor switch off the system appearance, cross-platform. auto-dark
;; detects light/dark (D-Bus on Linux, ns-system-appearance/AppleScript on
;; macOS) and runs the mode hooks; we keep catppuccin as the single loaded theme
;; and only swap its flavor, so auto-dark must not load themes of its own
;; (hence the nil theme vars). Loaded after doom-themes so catppuccin is active
;; when `auto-dark-mode' applies the initial flavor.
;;
;; `auto-dark-allow-osascript' lets macOS detect appearance via the `osascript'
;; binary, which works in a terminal frame too (the AppleScript branch requires
;; a GUI `window-system', so `emacs -nw' would otherwise fall through).
;;
;; Some hosts have no detection mechanism at all (a Linux TTY/SSH session with
;; no D-Bus session bus). There `auto-dark-mode' would log "Could not determine
;; a viable theme detection mechanism!" at startup. `my/auto-dark-detectable-p'
;; mirrors auto-dark's own detection conditions without that warning side effect,
;; so we only enable the mode when it can work; otherwise we apply a fixed dark
;; flavor and stay quiet.
(use-package auto-dark
  :after catppuccin-theme
  :custom
  (auto-dark-dark-theme nil)
  (auto-dark-light-theme nil)
  (auto-dark-allow-osascript t)
  :config
  (defun my/auto-dark-detectable-p ()
    "Non-nil when a system-appearance detection method is available.
Mirrors `auto-dark--determine-detection-method' without its warning
side effect, so we can decide whether to enable `auto-dark-mode'."
    (cond
     ((eq system-type 'darwin)
      (or (memq window-system '(ns mac))              ; GUI -> applescript
          (and (bound-and-true-p auto-dark-allow-osascript)
               (executable-find "osascript"))))       ; terminal -> osascript
     ((eq system-type 'gnu/linux)
      (and (featurep 'dbus)
           (ignore-errors                             ; no session bus -> error
             (member "org.freedesktop.portal.Desktop"
                     (dbus-list-activatable-names :session)))))
     ((eq system-type 'windows-nt) t)
     (t nil)))
  (add-hook 'auto-dark-dark-mode-hook
            (lambda () (my/apply-catppuccin-flavor 'dark)))
  (add-hook 'auto-dark-light-mode-hook
            (lambda () (my/apply-catppuccin-flavor 'light)))
  (if (my/auto-dark-detectable-p)
      (auto-dark-mode)
    ;; No detectable mechanism (e.g. Linux TTY/SSH). Skip the mode and its
    ;; startup warning; apply a fixed dark flavor instead.
    (my/apply-catppuccin-flavor 'dark)))
#+end_src

** Icons and fonts

#+begin_src emacs-lisp
(use-package nerd-icons
  :custom
  (nerd-icons-font-family "MonaspiceNe Nerd Font"))

;; The `default' face is applied in `my/apply-monaspace-role-faces' (from the
;; flavour hook), not here: catppuccin re-specs `default' on every reload, which
;; would strip a top-level family/size/weight. variable-pitch and fixed-pitch
;; below are not themed by catppuccin, so they are safe to set once here.
;; Prose (variable-pitch) uses Xenon, the slab-serif face, to read distinctly
;; from Neon code. `mixed-pitch-mode' (enabled in org/markdown below) keeps
;; code, tables and verbatim in the fixed-pitch Neon face while body text uses
;; this.
(set-face-attribute 'variable-pitch nil
                    :font "MonaspiceXe Nerd Font"
                    :height 140
                    :weight 'medium)
(set-face-attribute 'fixed-pitch nil
                    :font "MonaspiceNe Nerd Font"
                    :height 140
                    :weight 'medium)
;; Italics render in Monaspace Radon (the script face). `italic' is the base
;; face inherited by org/markdown emphasis; font-lock-comment/keyword-face slant
;; themselves directly. These are all restyled by `catppuccin-reload', so they
;; are applied in `my/apply-monaspace-role-faces' (called from the flavour hook)
;; rather than here -- otherwise the reload auto-dark runs at startup wipes them.

(add-to-list 'default-frame-alist '(ns-transparent-titlebar . t))
(add-to-list 'default-frame-alist '(ns-appearance . dark))

(set-face-background 'fringe (face-attribute 'default :background))

;; Fallback for symbol glyphs Monaspace lacks (Dingbats + Misc Symbols &
;; Arrows). Menlo is a monospace face that covers e.g. ✳ (U+2733). Note: the
;; org-modern default L3 stars U+2BC8/U+2BC6 exist in no installed font, so
;; the org-modern-fold-stars override in the org-modern block is what actually
;; fixes level-3 headings.
(set-fontset-font t '(#x2700 . #x27bf) "Menlo" nil 'append)   ; Dingbats
(set-fontset-font t '(#x2b00 . #x2bff) "Menlo" nil 'append)   ; Misc Symbols & Arrows

;; org/markdown are deferred, so their heading faces don't exist when the
;; flavour hook first runs at startup. Re-apply the Monaspace role faces (which
;; colours the Krypton headings) once each loads, mirroring how the diff-hl
;; block re-invokes `my/apply-diff-hl-faces'.
(with-eval-after-load 'org
  (when (fboundp 'my/apply-monaspace-role-faces) (my/apply-monaspace-role-faces)))
(with-eval-after-load 'markdown-mode
  (when (fboundp 'my/apply-monaspace-role-faces) (my/apply-monaspace-role-faces)))
#+end_src

(Neon), so prose gets the slab-serif voice without breaking monospace
alignment. Enabled in org and markdown buffers.

The Roslyn server (=Microsoft.CodeAnalysis.LanguageServer=) does not auto-load a
workspace; it needs a =solution/open= (or =project/open=) notification after
init, which Eglot does not send. Without it Roslyn runs in miscellaneous-files
mode and flags every =using= directive as unused. Send it on connect, pointing
at the nearest =.sln= (top-level only) or falling back to every =.csproj=.

#+begin_src emacs-lisp
(defun my/eglot-roslyn-workspace-plan (root)
  "Return the Roslyn workspace-open plan for project ROOT, or nil.
Pure: inspects the filesystem only and returns a plist describing the
notification to send, leaving the eglot/jsonrpc call to the caller.  A
top-level .sln yields (:method :solution/open :path SLN); otherwise any
.csproj found recursively yields (:method :project/open :paths (CSPROJ...));
an empty project yields nil."
  (let ((sln (car (directory-files root t "\\.sln\\'"))))
    (cond
     (sln (list :method :solution/open :path sln))
     ((directory-files-recursively root "\\.csproj\\'")
      (list :method :project/open
            :paths (directory-files-recursively root "\\.csproj\\'")))
     (t nil))))

(defun my/eglot-roslyn-load-solution (server)
  "Point the Roslyn server at the nearest .sln (or all .csproj files).
Microsoft.CodeAnalysis.LanguageServer does not auto-load a workspace; it needs a
`solution/open' (or `project/open') notification after init, which Eglot does
not send.  Without it Roslyn runs in miscellaneous-files mode and flags every
using directive as unused."
  (when (memq 'csharp-ts-mode (eglot--major-modes server))
    (let ((plan (my/eglot-roslyn-workspace-plan
                 (project-root (eglot--project server)))))
      (pcase (plist-get plan :method)
        (:solution/open
         (jsonrpc-notify server :solution/open
                         (list :solution
                               (eglot-path-to-uri (plist-get plan :path)))))
        (:project/open
         (jsonrpc-notify server :project/open
                         (list :projects
                               (vconcat (mapcar #'eglot-path-to-uri
                                                (plist-get plan :paths))))))))))

(add-hook 'eglot-connect-hook #'my/eglot-roslyn-load-solution)

* JavaScript/TypeScript

The =add-node-modules-path= package defaults to running =npm bin= to locate the
directory, but that command was removed in npm v9, so it silently does nothing
on a modern toolchain. Instead, locate the nearest =node_modules/.bin= with
=locate-dominating-file= and prepend it to a buffer-local =exec-path= / =PATH=.
This is package-manager agnostic (npm/pnpm/yarn) and spawns no subprocess, and
runs on the mode hook so the project-local =typescript-language-server= (for a
manually-started =M-x eglot=) and =eslint= (for =flymake-eslint=) are already on
=exec-path=.

#+begin_src emacs-lisp
(defun my/add-node-modules-path ()
  "Prepend the nearest node_modules/.bin to a buffer-local `exec-path'.
Replaces `add-node-modules-path', whose `npm bin' default was removed in npm 9."
  (when-let* ((root (locate-dominating-file default-directory "node_modules"))
              (bin  (expand-file-name "node_modules/.bin" root)))
    (when (file-directory-p bin)
      (setq-local exec-path (cons bin exec-path))
      (setq-local process-environment
                  (cons (concat "PATH=" bin path-separator (getenv "PATH"))
                        process-environment)))))

(dolist (hook '(tsx-ts-mode-hook typescript-ts-mode-hook js-mode-hook))
  (add-hook hook #'my/add-node-modules-path))
